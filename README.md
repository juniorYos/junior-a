# Kritik & Saran Yosuka

Website aspirasi siswa OSIS SMA Yos Sudarso Karawang.

## Menjalankan

Buka `index.html` di browser.

## GitHub Pages

Aktifkan GitHub Pages di **Settings → Pages**, pilih **Deploy from a branch**, lalu pilih branch `main` dan folder `/ (root)`. Halaman utama akan dimuat dari `index.html`.

Data masukan tersimpan di browser/perangkat yang digunakan dan tidak tersinkron ke perangkat lain.
